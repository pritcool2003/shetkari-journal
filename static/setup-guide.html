Phase 1 — Accounts & Credentials
1

Create Telegram Bot

Get bot token from @BotFather and find your chat ID

›
  1. Open Telegram → search @BotFather
  2. Send /newbot
  3. Give it a name: Shetkari Journal
  4. Give it a username: shetkari_journal_bot (must end in _bot)
  5. Copy the token — looks like 7123456789:AAH...
💡
To get your Chat ID: search @userinfobot on Telegram → send /start → it shows your numeric ID. Save this as ALLOWED_CHAT_ID.
# Save these two values
TELEGRAM_BOT_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxxxxx
ALLOWED_CHAT_ID=123456789
2

Google Cloud Setup

Create project, enable APIs, create service account

›
  1. Go to console.cloud.google.com
  2. Create new project → name it shetkari-journal
  3. Enable Google Sheets API (search in APIs & Services)
  4. Enable Google Drive API
  5. Go to IAM & Admin → Service Accounts
  6. Create service account → name: shetkari-bot
  7. Click the account → Keys tab → Add Key → JSON
  8. Download the JSON file — keep it safe!
⚠️
Never commit the credentials JSON to git. Add credentials.json to your .gitignore. On Render, paste the entire JSON content as the GOOGLE_SERVICE_ACCOUNT_JSON env variable.
3

Google Sheet & Drive Setup

Create the spreadsheet and Drive folder, share with service account

›

Google Sheet:

  1. Go to sheets.google.com → create new spreadsheet
  2. Name it: Shetkari Journal 2025-26
  3. Click Share → paste service account email (from JSON: client_email) → Editor access
  4. Copy Sheet ID from the URL:
    docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit

Google Drive Folder:

  1. Go to drive.google.com → New → Folder
  2. Name it: Shetkari-Journal
  3. Right-click → Share → paste service account email → Editor
  4. Open the folder → copy ID from URL:
    drive.google.com/drive/folders/FOLDER_ID_HERE

6

Deploy on Render

Free web service, auto-deploys from GitHub

›
  1. Go to render.com → New → Web Service
  2. Connect your GitHub repo
  3. Settings:
    • Runtime: Python 3
    • Build Command: pip install -r requirements.txt
    • Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT
    • Plan: Free
  4. Click Advanced → Add Environment Variables (see next step)
  5. Click Create Web Service
  6. Wait for deployment → copy your URL: https://shetkari-journal.onrender.com
⚠️
Free Render services sleep after 15 min of inactivity. The first webhook after sleep takes ~30 seconds. For a single personal user this is fine — the bot wakes up on first message of the day.
7

Set Environment Variables on Render

All 6 required variables — paste directly in Render dashboard

›
VariableValue / Where to get it
TELEGRAM_BOT_TOKEN Token from @BotFather required
ALLOWED_CHAT_ID Your numeric Telegram ID from @userinfobot optional
OPENAI_API_KEY From platform.openai.com → API Keys required
GOOGLE_SHEET_ID ID from Google Sheet URL required
GOOGLE_DRIVE_ROOT_FOLDER_ID ID from Shetkari-Journal Drive folder URL required
GOOGLE_SERVICE_ACCOUNT_JSON Paste the entire content of credentials.json as a single line required
WEBHOOK_URL Your Render URL e.g. https://shetkari-journal.onrender.com required
💡
For GOOGLE_SERVICE_ACCOUNT_JSON: open credentials.json → Select All → Copy → paste directly into Render's value field. It's a long JSON string starting with {"type":"service_account"...
